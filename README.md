# Python Chapter 3 — Practice Set

This repository contains my solutions to the **Python Chapter 3 Practice Set**.

The exercises focus on strings, user input, string formatting, detecting and replacing spaces, and using escape sequence characters.

## Questions Covered

### 1. Display a Greeting

Write a Python program to display a user-entered name followed by **"Good Afternoon"** using the `input()` function.

### 2. Fill in a Letter Template

Write a program to fill in the following letter template with a name and date:

```python
letter = '''
Dear <|Name|>,
You are selected!
<|Date|>
'''
```

The program replaces the placeholders with the appropriate name and date.

### 3. Detect Double Spaces

Write a Python program to detect double spaces in a string.

### 4. Replace Double Spaces

Write a program to replace the double spaces found in Problem 3 with single spaces.

### 5. Format a Letter Using Escape Sequences

Write a Python program to format the following letter using escape sequence characters:

```python
letter = "Dear Harry, this python course is nice. Thanks!"
```

## Topics Practiced

- Python strings
- `input()` function
- String formatting
- String replacement
- Finding text in strings
- Detecting double spaces
- Replacing double spaces
- Escape sequences
- New lines and formatting

## Learning Goal

The goal of this practice set is to apply the concepts learned in **Python Chapter 3** through practical string manipulation and formatting problems.
